# Diagram sources

Mermaid sources for the nine figures in the framework paper. Each file is named for the figure asset it renders (assets/images/<name>.png). The PNGs in assets/images were rendered from these sources during the v1.3/v1.4 cycle; regenerate with mermaid-cli (mmdc -i <name>.mmd -o ../assets/images/<name>.png) or any mermaid renderer. The single-file markdown export (dist/GATE-v1.4-current.md) inlines these sources as mermaid code fences instead of linking the PNGs.
